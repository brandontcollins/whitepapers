# Close the Loop: Software Engineering Standards

This directory contains the source files and release artifacts for the whitepaper **“Close the Loop: Software Engineering Standards for Code, Data, and Delivery”.**

## Structure

- `src/` – Source files for the whitepaper (Markdown, images, diagrams, build config).  
- `dist/` – Published PDFs, including versioned releases (for example, `close-the-loop-software-engineering-standards_v1.0.0.pdf`).
